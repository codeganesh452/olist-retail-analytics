# Olist Retail Analytics — End-to-End Data Analyst Project

## Project Overview

This project analyzes Olist e-commerce data to explore sales performance, customer behavior, product categories, sellers, delivery performance, and customer reviews.

The project uses SQL Server for data analysis and Power BI to build a four-page interactive report.

## Tools Used

* SQL Server Management Studio (SSMS)
* SQL
* Power BI
* DAX

## Project Workflow

1. Imported the Olist dataset into SQL Server.
2. Cleaned and prepared the data.
3. Completed SQL analysis across sales, customers, products, orders and delivery, sellers, reviews, payments, and executive business insights.
4. Connected Power BI to SQL Server and created the data model and relationships.
5. Created DAX measures and built four report pages.

## Power BI Dashboards

### 1. Executive Overview

Provides a company-wide overview of sales, revenue, average order value, orders, delivery time, order status, state-level revenue, and monthly revenue.

### 2. Sales & Product

Explores sales by product category, top product IDs by units sold, monthly sales, and payment type.

### 3. Customer & Seller

Shows customer distribution by state and city, seller revenue, and customer purchase frequency.

### 4. Delivery & Review

Analyzes delivery time, on-time and late delivery rates, and customer review ratings.

## Key Business Insights

* The report shows approximately 99K orders and 13.59M in total sales.
* Total revenue, including freight, is approximately 15.84M.
* Health & Beauty is the leading category by revenue in the displayed category chart.
* São Paulo has the highest state-level revenue and customer count in the displayed visuals.
* The report shows an on-time delivery rate of approximately 92.13% and a late delivery rate of approximately 7.87%.
* The average review score is approximately 4.09 out of 5.
* Credit card is the largest payment type by payment value in the displayed chart.

*Figures are rounded from the Power BI report. Revenue and sales use the currency displayed in the report.*
